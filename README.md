# AI Negotiation Simulator

A practice tool for everyday negotiations, built by Vittesh Maganti as an independent project. Eight scenarios cover pay negotiations, scheduling, and workplace conflict.

In each scenario the counterpart tracks two scores, the deal for you and the relationship, and reacts to every move you choose. If trust falls too far they end the conversation. Each run finishes with a debrief that names the tactic behind every move and what it earned or cost.

This web version runs entirely in the browser as a single static `index.html`, published with GitHub Pages.
